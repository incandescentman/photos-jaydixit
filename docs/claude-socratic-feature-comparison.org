* Overview

This document compares features from the socratic app that could benefit photos-jaydixit, a photography portfolio site.
All feature decisions in this document are owner decisions (Jay).

* Implementation Snapshot (2026-02-18)

** Completed Decisions
- Structured data (JSON-LD): IMPLEMENTED
  - Site-level WebSite JSON-LD plus page-level Blog, BlogPosting, ImageGallery, and Photograph schemas.
- Twitter cards: IMPLEMENTED
  - Centralized twitter:* meta tags in MainLayout with per-page overrides.
- Social share button: IMPLEMENTED
  - New reusable component on gallery and blog detail pages.
- RSS feed: IMPLEMENTED
  - Existing /feed.xml retained; discovery link now emitted globally in head.
- Analytics: IMPLEMENTED (env-gated)
  - Google Analytics wiring added; activate with PUBLIC_GA_MEASUREMENT_ID.
- Sitemap: IMPLEMENTED
  - @astrojs/sitemap integrated in Astro config.
- Per-photo pages: IMPLEMENTED
  - Canonical route: /gallery/photo/<folder>/<photo-slug>
  - Canonical URL dedupes .jpg/.webp variants to one photo URL.
- Per-photo comment threads: IMPLEMENTED
  - Giscus term now uses canonical per-photo slug on photo detail pages.

** Recent Commits
- e3bf67f - Implement SEO, sharing, analytics, and sitemap features
- 5f34cd3 - Add per-photo gallery pages with navigation and comments
- db8dba9 - Canonicalize per-photo URLs across image formats

* High Priority Features

** Dark Mode Support
- Status: MISSING
- Socratic has: ApplyColorMode component, CSS variables, theme toggle
- photos-jaydixit has: None
- Impact: Critical for photography portfolio - viewers often prefer dark backgrounds
- Approach: Port ApplyColorMode.astro pattern, add CSS variables for theme colors

Decision: DEFER 

** Structured Data (JSON-LD)
- Status: MISSING
- Socratic has: Person, Article, Organization, FAQPage schemas
- photos-jaydixit has: None
- Impact: SEO boost for image search, Google Images integration
- Approach: Add ImageGallery, ImageObject, Photograph schemas for albums/photos

Decision: add 


** Twitter Cards
- Status: PARTIAL
- Socratic has: Full twitter:card, twitter:image, twitter:creator tags
- photos-jaydixit has: Only basic OpenGraph tags
- Impact: Better sharing previews on Twitter/X
- Approach: Add twitter meta tags to BaseHead component


Decision: add



** Social Share Button
- Status: MISSING
- Socratic has: SocialShare.astro with copy-to-clipboard, glass-morphism UI
- photos-jaydixit has: None
- Impact: Easy sharing of albums and individual photos
- Approach: Port SocialShare.astro component, adapt for photo context


Decision: add

* Nice-to-Have Features

** Per-Photo Pages
- Status: MISSING
- Socratic has: Individual post pages with slug routing
- photos-jaydixit has: Gallery pages only, no individual photo routes
- Impact: Deep-linking to specific photos, better SEO for individual images
- Approach: Add /gallery/[folder]/[photo].astro dynamic route

** Per-Photo Comment Threads
- Status: PARTIAL
- Socratic has: Comments per post
- photos-jaydixit has: Giscus comments per gallery only
- Impact: Discussions about specific photos rather than entire galleries
- Approach: Pass photo filename to Giscus data-term on per-photo pages


Decision: REJECT


** Most-Liked Photos Page
- Status: MISSING
- Socratic has: N/A
- photos-jaydixit has: Like button infrastructure ready
- Impact: Surface popular content, encourage engagement
- Approach: Query Supabase for top-liked photos, create /popular page

Decision: defer until we have supabase 

** Tag Analytics & Popularity Ranking
- Status: MISSING
- Socratic has: Tag pages with counts
- photos-jaydixit has: Tags extracted but no analytics
- Impact: Show trending tags, popular subjects/events
- Approach: Aggregate likes by tag, display tag cloud with popularity weighting

** Location/Date Metadata
- Status: PARTIAL
- Socratic has: Post dates
- photos-jaydixit has: Year from filename, no location
- Impact: Filter by date range, map view of photos
- Approach: Extend filename convention or use JSON sidecar files

** Image Upload UI
- Status: MISSING
- Socratic has: N/A (content in repo)
- photos-jaydixit has: Manual folder management
- Impact: Easier photo management for non-technical workflow
- Approach: Admin page with drag-and-drop upload to Cloudinary

** EXIF Data Display
- Status: DEPENDENCY EXISTS, UNUSED
- Socratic has: N/A
- photos-jaydixit has: exifr package installed but not used
- Impact: Show camera, lens, aperture, shutter speed
- Approach: Extract EXIF on build, display in photo detail view

Decision: add

** Related Albums
- Status: MISSING
- Socratic has: RelatedPosts component
- photos-jaydixit has: None
- Impact: Keep visitors exploring
- Approach: Adapt RelatedPosts pattern for albums by tag/theme

** Reading Time for Blog
- Status: MISSING
- Socratic has: readingTimeRemarkPlugin
- photos-jaydixit has: Blog collection but no reading time
- Impact: Minor UX improvement
- Approach: Already available in @jaydixit/astro-utils, add to config

Decision: reject 

** Breadcrumb Navigation
- Status: MISSING
- Socratic has: AnchorHeading pattern
- photos-jaydixit has: Basic nav only
- Impact: Better navigation in nested galleries
- Approach: Add breadcrumb component

Decision: add
