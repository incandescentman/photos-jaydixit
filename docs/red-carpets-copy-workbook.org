* Purpose
This workbook contains all page-specific text currently used by [[http://localhost:4322/red-carpets][Red Carpets Around the World]]. It is meant to help Jay replace that language in his own words.

Shared site navigation and footer text are not included because they belong to the site-wide interface, not this page. Visual-only numbers, geographic coordinates, proper names, and generated labels are included where they affect what a visitor reads, hears through a screen reader, or sees in a search or social preview.

The live sources are:

* How to use this workbook
Under each prompt, write whatever comes naturally. Fragments, memories, sensory details, and blunt statements are useful. Do not try to make the answers polished or concise yet. If the current text is already right, write ~KEEP~. If a factual label is wrong, correct it directly.
