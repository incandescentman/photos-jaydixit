* Overview

This document captures recommendations for elevating the visual design of [[file:///Users/jay/Dropbox/github/photos-jaydixit][photos.jaydixit.com]] from "clean and functional" to "distinctive and memorable."

* Typography Upgrade
:PROPERTIES:
:PRIORITY: High
:EFFORT: Low
:END:

** Current State
Playfair Display + Inter (common pairing)

** Proposed Options

*** Option A: Editorial
- Display: Cormorant Garamond
- Body: Karla
- Vibe: Magazine-quality, refined

*** Option B: Contemporary
- Display: Syne
- Body: Space Mono
- Vibe: Art-world, gallery feel

*** Option C: Warm Documentary
- Display: Fraunces
- Body: Source Sans 3
- Vibe: Humanist, storytelling

** Quick Win
Replace Inter with *Karla* (more personality, still readable) and keep Playfair, or swap Playfair for *Cormorant Garamond* (more elegant, less overused).

* Color System with Intention
:PROPERTIES:
:PRIORITY: High
:EFFORT: Low
:END:

** Current State
- Neutral off-white (#f9f9f9)
- Near-black text
- Scattered blue/red accents

** Proposed: Warm Film Stock Palette

Creates a *warm, tactile feeling* like handling printed photographs---distinct from the cold minimalism of most portfolio sites.

#+begin_src css
/* Warm Film Stock palette */
--bg-primary: #FAF8F5;        /* Warm paper white */
--bg-secondary: #F3EDE4;      /* Cream shadow */
--text-primary: #2C2825;      /* Warm charcoal */
--text-muted: #6B635A;        /* Stone gray */
--accent: #C4A77D;            /* Brass/bronze */
--accent-hover: #8B7355;      /* Aged bronze */
#+end_src

* Gallery Layout Enhancement
:PROPERTIES:
:PRIORITY: Medium
:EFFORT: Medium
:END:

** Current State
CSS columns (works but static)

** Proposed Enhancements

*** Hero Image Treatment
First photo in each gallery spans 2 columns, larger scale.

*** Varied Spacing
Intentional gaps (~1.25rem~ on some rows, ~0.75rem~ on others).

*** Asymmetric Touches
Let some images break the grid slightly with negative margins.

#+begin_src css
/* Featured image treatment */
.gallery-item:first-child {
  column-span: all;
  margin-bottom: 2rem;
}

.gallery-item:nth-child(5n+2) {
  transform: translateX(-4px);
}
#+end_src

* Immersive Lightbox Experience
:PROPERTIES:
:PRIORITY: Medium
:EFFORT: Medium
:END:

** Current State
GLightbox with standard dark overlay

** Proposed: Full Cinematic Treatment

#+begin_src css
/* Deeper blacks, slower transitions */
.glightbox-container {
  background: #0a0a0a;
}

.gslide-media {
  animation: subtle-focus 0.6s cubic-bezier(0.16, 1, 0.3, 1);
}

@keyframes subtle-focus {
  from {
    opacity: 0;
    transform: scale(0.97);
    filter: blur(2px);
  }
  to {
    opacity: 1;
    transform: scale(1);
    filter: blur(0);
  }
}

/* Caption treatment */
.gslide-description {
  font-family: 'Karla', sans-serif;
  letter-spacing: 0.05em;
  text-transform: uppercase;
  font-size: 0.75rem;
  color: rgba(255,255,255,0.6);
}
#+end_src

* Hover States with Depth
:PROPERTIES:
:PRIORITY: High
:EFFORT: Low
:END:

** Current State
Subtle lift + shadow increase

** Proposed: Tactile Photo Interactions

Creates a *"picking up a photo"* feeling and draws focus to the hovered image.

#+begin_src css
.gallery-item {
  transition: all 0.4s cubic-bezier(0.23, 1, 0.32, 1);
}

.gallery-item:hover {
  transform: translateY(-6px) rotate(-0.5deg);
  box-shadow:
    0 25px 50px -12px rgba(0,0,0,0.15),
    0 0 0 1px rgba(255,255,255,0.1) inset;
}

/* Subtle desaturation on non-hovered items */
.gallery:hover .gallery-item:not(:hover) {
  filter: saturate(0.7);
  opacity: 0.85;
}
#+end_src

* Page Transitions & Entry Animations
:PROPERTIES:
:PRIORITY: Medium
:EFFORT: Low
:END:

** Current State
Minimal animation on load

** Proposed: Staggered Reveal

#+begin_src css
.gallery-item {
  opacity: 0;
  transform: translateY(20px);
  animation: reveal 0.5s ease-out forwards;
}

.gallery-item:nth-child(1) { animation-delay: 0.1s; }
.gallery-item:nth-child(2) { animation-delay: 0.15s; }
.gallery-item:nth-child(3) { animation-delay: 0.2s; }
/* ... continue pattern */

@keyframes reveal {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
#+end_src

* Header Refinement
:PROPERTIES:
:PRIORITY: Low
:EFFORT: Medium
:END:

** Current State
Standard sticky header with blur

** Proposed: Editorial Presence

- Reduce logo size slightly and add more breathing room
- Add a subtle bottom border that appears on scroll (not shadow)
- Consider split navigation: Logo left, links right with generous spacing
- On gallery pages: Header could be transparent initially, solidifying on scroll

#+begin_src css
/* Editorial header feel */
.header {
  border-bottom: 1px solid transparent;
  transition: all 0.3s ease;
}

.header.scrolled {
  border-bottom-color: rgba(0,0,0,0.08);
  backdrop-filter: blur(12px) saturate(1.2);
}
#+end_src
